# АРМ прокуратуры — учёт, протоколы, подбор норм права

Статический сайт (React + Vite + Tailwind CSS) для GitHub Pages. Серверная часть не нужна.

## Возможности

- **Реестр материалов** — регистрация обращений и проверок, статусы, контрольные сроки, поиск, печать журнала.
- **Документы и протоколы** — 8 шаблонов (постановление о возбуждении дела об АП, объяснение, представление,
  предостережение, требование, справка по проверке, протокол приёма, ответ заявителю). Данные из реестра
  подставляются автоматически. Печать на А4 «с заполнением» или **пустым бланком**.
- **Законодательство (КонсультантПлюс)** — каталог статей КоАП, УК, УПК, ФЗ «О прокуратуре», ГПК, КАС, 59-ФЗ:
  поиск, подборка, печать подборки, прикрепление статей к документам, выписка из норм.
  Кнопки открывают нужную статью/кодекс на consultant.ru, текст можно вставить и сохранить.
- **Данные** сохраняются в браузере (localStorage). Есть выгрузка/загрузка резервной копии в JSON.

> Сайт consultant.ru не предоставляет открытого API, поэтому прямой выгрузки текста статей нет: используйте ссылки
> на КонсультантПлюс и вставку текста в карточку статьи.

## Как выложить на GitHub Pages

1. Создайте репозиторий на github.com (кнопка **New repository**), например `prokuratura`.
2. Загрузите в него **все файлы из этой папки** (в том числе скрытую папку `.github`):
   - через веб-интерфейс: **Add file → Upload files**, перетащите содержимое папки (папку `.github` тоже);
     либо через Git:
     ```bash
     git init
     git add .
     git commit -m "Первый коммит"
     git branch -M main
     git remote add origin https://github.com/ВАШ_ЛОГИН/prokuratura.git
     git push -u origin main
     ```
3. В репозитории откройте **Settings → Pages** и в разделе **Build and deployment → Source** выберите
   **GitHub Actions**.
4. Перейдите во вкладку **Actions** — дождитесь зелёной галочки у workflow «Deploy to GitHub Pages».
5. Сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/prokuratura/`.

Каждый следующий `push` в ветку `main` автоматически обновляет сайт.

### Вариант без Actions (готовый файл)

Сборка создаёт **один файл** `dist/index.html` (всё встроено внутрь). Выполните локально:

```bash
npm install
npm run build
```

Затем загрузите `dist/index.html` в корень отдельного репозитория (или в ветку `gh-pages`) и в
**Settings → Pages** выберите **Deploy from a branch** → нужную ветку → `/ (root)`.

## Локальный запуск

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/
```

## Важно

Это вспомогательный инструмент, а не официальный сайт органов прокуратуры. Шаблоны носят справочный характер —
сверяйте их с действующими нормативными актами и ведомственными приказами. Не храните в открытом репозитории
персональные данные: данные из программы остаются только в браузере пользователя.
